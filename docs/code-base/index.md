This section provides high-level documentation for the services and codebases that support the Planning Data platform.

Each page explains the purpose of a service, the people and processes it supports, how it fits into the wider platform, and where to find more detailed documentation.

### [Check and Provide](check-and-provide/)

The service data owners use to check their planning data against a specification and provide it to the platform. It is the entry point for data arriving on the platform.

### [Manage service](manage-service/)

The service data managers use to review, configure and add data to the Planning Data platform.

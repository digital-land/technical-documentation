* [Git](/development/best-practice/git) - branch naming and repository conventions
* [Make](/development/best-practice/make) - conventions for makefiles and make targets
* [Pull requests](/development/best-practice/pull-requests) - raising a pull request and getting it reviewed
* [Python](/development/best-practice/python) - managing Python versions and dependencies
